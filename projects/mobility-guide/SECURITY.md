# 보안·안전 검토

## 적용한 통제

| 영역 | 구현 | 확인할 점 |
| --- | --- | --- |
| API 키 | `.env`는 `.gitignore` 대상이며 철도 요청 도구만 읽습니다. 권한 `0600`을 강제하고 요청 URL·예외 원문을 출력하지 않습니다. | 저장소를 만들거나 공유하기 전 `.env`와 `.private/`가 추적되지 않는지 확인 |
| 전송 | OSM 한국 원자료는 Geofabrik의 HTTPS에서 키 없이 받고 공식 MD5와 대조했습니다. 철도 자료는 HTTPS와 인증서 검증을 사용하고 리다이렉트를 거부합니다. 서울시 API의 HTTP 예시로는 키를 보내지 않습니다. | 서울시가 안전한 HTTPS API를 제공하면 별도로 재검증 |
| 위치 개인정보 | iOS의 사용 중 위치 권한만 요청합니다. 자체 A*용 위치·이동 설정은 앱 메모리에 둡니다. 일반 보행에서 Apple 보행 경로·장거리 대중교통 시간을 조회하면 출발지·목적지 좌표를 Apple 지도 서비스에 전송하며 화면에 고지합니다. 앱 자체 계정·분석 기능은 없습니다. | Apple 지도 서비스의 개인정보 처리와 실제 네트워크 동작은 별도 확인 |
| 외부 자료 | PBF 파서가 읽은 OSM 노드 ID가 같은 보행로만 연결하고 보행 제한·계단·일방향을 처리합니다. 좌표·길이를 검사하며 자료 범위 밖은 경로 계산 전에 알립니다. 서울시 CSV는 별도 보관합니다. | OSM 표기 누락·오류와 실제 출입구·보도 위치는 현장 확인 필요 |
| 화면 내용 | 철도 안내 문구를 SwiftUI `Text`로만 표시하며 원격 HTML·이미지를 실행하거나 렌더링하지 않습니다. | 공식 이미지 이용 조건과 URL을 확인한 뒤 별도 추가 가능 |
| 경로 안전 | 휠체어 설정은 계단·에스컬레이터와 확인·추정 경사가 개인 한도를 넘는 링크를 제외하고 Apple 보행 경로를 제시하지 않습니다. 지형 추정은 현장 확인으로 승격하지 않으며, 휠체어에는 별도 미확인 후보만 보여주고 안전 경로로 추천하거나 안내를 시작하지 않습니다. 출발·도착 접속 간격도 별도 표시합니다. | 추정 오차로 후보가 줄어들 수 있고 미확인 구간의 통행 가능성은 보장하지 않음 |
| 자료 사용 조건 | 변환 보행망은 ODbL 1.0 파생 자료로 분리하고 앱에 `© OpenStreetMap contributors` 및 라이선스 링크를 표시합니다. | 배포 전 파생 DB 제공 방식과 추가 자료 결합 조건 확인 |

## 현재 남은 위험

1. 앱에 포함한 OSM 추출본은 2026-09-27자입니다. 도로 공사, 턱, 보도 폭, 경사와 엘리베이터 운행 상태가 이후 변했거나 OSM에 누락됐을 수 있습니다. 도로 중심선이 실제 보도 위치와 다를 수 있습니다.
2. 개봉역의 공식 출입구→승강장 API 응답 및 실제 접근 가능한 출입구 연결은 아직 검증되지 않았습니다. 자료가 비어 있는 동안 실내 안내는 숨깁니다.
3. GPS 오차가 큰 장소에서는 길이 잘못된 보행 링크에 붙을 수 있습니다. 앱은 수평 정확도 30m 초과 또는 오래된 위치에서 경로를 지우며, 지도 보행로까지의 접속 거리를 따로 표시합니다.
4. 공식 API 문서의 `imgPath`는 앱에서 바로 열지 않습니다. 출처·라이선스·HTTPS 호스트를 검증하기 전 원격 이미지 로드는 추가하지 않습니다.
5. 현재 작업 폴더는 Git 저장소가 아니어서 과거 커밋의 비밀정보 유출 여부를 검사할 수 없습니다. 실제 키를 입력한 뒤 저장소를 만들 경우 먼저 추적 파일 목록을 검사해야 합니다.
6. OSM은 `oneway:foot`과 에스컬레이터의 명시적 방향만 반영합니다. 방향 표기가 없는 보행로는 양방향으로 가정합니다. 시청→종각 검색 중심의 가까운 고립 구간은 우회하지만, 약 2.3km의 자체 보행망 경로와 목적지까지 남은 접속 구간은 실제로 검증되지 않았습니다.
7. 제공된 `서울시 경사도/`의 2023년 기준 표고점·등고선으로 299,562개 링크에 추정 경사를 연결했습니다. 실측값으로 승격하지 않으며, 사용자 선택에 따라 참고 후보에서도 추정 한도 초과를 제외합니다. 보간 표본 거리·삼각형 크기를 제한해도 실제 오차는 보장되지 않습니다. 교량·터널·비지상 층 표기는 지형 적용에서 제외하지만 OSM 표기 누락은 남아 있습니다. 작은 턱·짧은 경사로·보도 횡경사는 반영하지 못하며 전체 링크 최대 경사를 부분 링크에도 적용하므로 후보가 과도하게 줄거나 ETA가 커질 수 있습니다.
8. 원본 SHP의 XML 메타데이터에 제작 기관의 내부 파일 경로가 포함되어 있습니다. GIS 원본 확장자를 `.gitignore`에서 제외해 저장소에 우연히 올라가지 않도록 했습니다. 자료를 별도로 공유할 때도 메타데이터를 확인해야 합니다.
9. 지형 프로필을 포함한 보행망은 약 215MiB입니다. 이전 판의 iPhone 17 시뮬레이터 첫 화면은 실행·확인했지만 새 자료의 실기기 로딩 시간·메모리와 VoiceOver 동작은 아직 측정하지 않았습니다.
10. Apple 지도 보행 대안은 계단·경사·출입구 접근성을 제공하지 않습니다. 일반 보행에만 표시하고, 경로 카드와 상세 화면에 미확인 상태를 명시합니다. 서버가 합리적인 대안을 제공하지 않으면 여러 선택지가 보장되지 않습니다.
11. 서울 API의 기본 HTTP 주소에 키를 넣지 않습니다. 인증키 없이 시험한 `https://openapi.seoul.go.kr:8088/`는 TLS 연결에 실패했고 표준 HTTPS 주소는 시간 초과였습니다. AWS의 공개 HTTPS 중계만으로 상류 HTTP 구간의 키 노출 문제는 해결되지 않습니다. 해당 API의 공식 HTTPS 주소를 확인하기 전에는 서울 키를 Lambda에도 올리지 않습니다. 공개 중계 시에는 입력값 제한, 호출량 제한, 비용 경보와 로그의 URL·키 삭제가 필요합니다.

2026-09-29 검사: `.env` 권한 `0600`, 앱 번들에 `.env` 없음, 저장된 키 값 1개와 소스·보행망·앱 번들 27개 파일의 일치 0건, 앱 번들 보행망과 원본의 SHA-256 일치. 위치 권한 설명도 실제 보행 경로 기능에 맞게 수정했습니다. 작업 폴더가 Git 저장소가 아니므로 추적 이력 검사는 수행할 수 없습니다.

2026-10-08 재검사: 최종 시뮬레이터 빌드 이후 소스·문서·프로젝트·자료·앱 번들 35개 파일에서 저장된 키와 일치하는 값 0건, `.env` 권한 `0600`, 앱 번들에 dotenv 파일 없음, 보행망·역내 안내 리소스의 원본/번들 SHA-256 일치를 확인했습니다. 이 검사는 저장된 키의 정확한 값 포함 여부를 검사하며 모든 형태의 비밀정보 유출을 증명하는 검사는 아닙니다. 두 서울 API의 공식 상세 명세를 포털과 같은 POST 방식으로 다시 읽었으나 예시 주소는 여전히 HTTP였습니다. 실제 키는 전송하지 않았으며 AWS 배포도 수행하지 않았습니다.

UI 자동화는 `Computer Use permissions are not granted`로 차단됐습니다. 시뮬레이터 실행·첫 화면 캡처와 핵심 경로 검사는 확인했지만 검색·핀 지정·프로필 변경·우회 경로 표시를 직접 누르는 전체 흐름은 미검증입니다.

2026-10-08 탐색 성능·디자인 수정: 라우터의 불변 연결표 재사용, 위도 범위 사전 필터와 필요한 노드만 확장하는 방식으로 변경했습니다. 합성 그래프 및 실제 네 구간의 A*/Dijkstra 비용 일치, 계단·에스컬레이터·미확인 경사의 기존 제한 검사와 시뮬레이터 빌드를 통과했습니다. 긴 링크 중간 접속 및 날짜 변경선 회귀 검사도 포함했습니다. 초록색은 선택된 경로의 시각 표시이며 접근성 검증 완료를 뜻하지 않습니다. 자체 보행망 미확인 구간의 점선, 경사 정보의 미확인 문구와 안내 시작 제한을 유지합니다. 실제 앱 화면에서의 체감 시간과 새 경로선 디자인은 직접 조작 검증이 남아 있습니다.

## 공개 전 확인

2026-10-09: 지형 추정과 실측 확인을 분리하고, 추정 한도 초과 제외·역방향 경사·부분 고도 단면·A*/Dijkstra 비용 일치 검사를 통과했습니다. 시뮬레이터 빌드 이후 42개 파일에서 저장된 키와 일치하는 값 0건, `.env` 권한 `0600`, dotenv 미포함과 번들 자료 해시 일치를 확인했습니다. 개봉성당→서울역 본관의 자체 보행 후보는 과도하게 우회하고 휠체어 후보는 없어 이 구간을 적절한 길찾기 결과로 인정하지 않습니다. 안전 제한을 해제하거나 없는 연결을 직선으로 만들지 않았습니다.
