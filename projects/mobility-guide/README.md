# 이동권 길찾기

프로젝트 목적·구현·한계는 [메인 포트폴리오](../../README.md)에 정리했습니다.

## 실행 안내

Xcode에서 MobilityGuide.xcodeproj를 연다. Data/network.json은 원본에서 별도로 준비해야 한다.

현재 사본에서 앱 실행·외부 API·기기 동작을 재검증하지 않았습니다. 비밀값, 개인 데이터와 빌드 산출물은 포함하지 않습니다.
