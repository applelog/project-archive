# 《인생의 길 (The Path of Life)》 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a standalone executable narrative journey game within the strict 1,474,560-byte (1.44MB floppy) competition limit, depicting a full human life from infant first-person perspective to gradual aging and death with scenic memory reminiscence, powered by C/C++ and Nintendo-style size optimization techniques.

**Architecture:** Data-oriented modular C design. Zero pre-rendered audio files (embedded 4-channel chiptune synthesizer), zero large texture sheets (procedural metatile + palette cycling LUT), dynamic character morphology interpolation, and a decoupled scenario table with a memory snapshot recorder for the final reminiscence sequence.

**Tech Stack:** C99 / C++, Raylib (static/minimal linking), custom 4-channel APU synthesizer, custom bitmap UI & Korean text renderer, Python size-audit script in Conda `min` environment.

## Global Constraints

- **Exact Byte Limit**: Total standalone executable and assets uncompressed must NOT exceed `1,474,560` bytes.
- **Standalone Executable**: Must run directly as a native executable; no web browser dependencies.
- **Development Environment**: Conda environment `min` (`/opt/homebrew/Caskroom/miniforge/base/envs/min/bin/python3`).
- **Optimization Philosophy (Ponytail / Nintendo Style)**: Build the minimum that works with maximum efficiency. No boilerplate, no unnecessary runtime layers.
- **Core Life Flow**:
  - Infant 1st-person POV (blurry vision, eye blink mechanic, sensory babbling, memory jumps) $\to$ first-step zoom-out transition to 3rd-person.
  - Continuous, seamless physical aging and palette morphing.
  - Non-linear psychological time acceleration (slow childhood $\to$ exponential rush towards old age $\to$ slow physical walk in winter).
  - Death & Scenic Reminiscence: Replaying actual recorded player decisions/moments as a cinematic memory album before final peace.
  - Fully modular scenario table that runs a complete test scenario and can be swapped easily.

- [ ] **Step 1: Write the size checker script in Python**

```python
#!/usr/bin/env python3
import os
import sys

LIMIT_BYTES = 1474560

def check_size(filepath):
    if not os.path.exists(filepath):
        print(f"[ERROR] Target file not found: {filepath}")
        sys.exit(1)
    
    size = os.path.getsize(filepath)
    rem = LIMIT_BYTES - size
    ratio = (size / LIMIT_BYTES) * 100
    
    print("=" * 50)
    print(" 1.44MB GAME SIZE AUDIT (2P GAME ARCADE)")
    print("=" * 50)
    print(f" Target File  : {filepath}")
    print(f" File Size    : {size:,} bytes")
    print(f" Disk Limit   : {LIMIT_BYTES:,} bytes (1.44MB HD Floppy)")
    print(f" Usage Ratio  : {ratio:.2f}%")
    print(f" Free Space   : {rem:,} bytes")
    print("=" * 50)
    
    if size > LIMIT_BYTES:
        print(f"[FAILED] EXCEEDED LIMIT BY {abs(rem):,} BYTES!")
        sys.exit(1)
    else:
        print("[PASSED] WITHIN 1.44MB LIMIT!")
        sys.exit(0)

if __name__ == "__main__":
    target = sys.argv[1] if len(sys.argv) > 1 else "bin/game"
    check_size(target)
```

```makefile
CC ?= clang
CFLAGS = -Wall -Wextra -std=c99 -O2 -I/opt/homebrew/include -Isrc

RELEASE_LDFLAGS = -L/opt/homebrew/lib -lraylib -framework OpenGL -framework Cocoa -framework IOKit -framework CoreVideo -framework CoreAudio

SRC = $(wildcard src/*.c)
OBJ = $(SRC:.c=.o)
TARGET = bin/game

all: $(TARGET)

$(TARGET): $(SRC)
	@mkdir -p bin
	$(CC) $(CFLAGS) $(SRC) $(LDFLAGS) -o $(TARGET)
	@/opt/homebrew/Caskroom/miniforge/base/envs/min/bin/python3 scripts/check_size.py $(TARGET)

release: $(SRC)
	@mkdir -p bin
	$(CC) $(RELEASE_CFLAGS) $(SRC) $(RELEASE_LDFLAGS) -o $(TARGET)
	@strip $(TARGET) 2>/dev/null || true
	@/opt/homebrew/Caskroom/miniforge/base/envs/min/bin/python3 scripts/check_size.py $(TARGET)

clean:
	rm -rf bin src/*.o

run: $(TARGET)
	./$(TARGET)

.PHONY: all release clean run
```
