# 《인생의 길 (The Path of Life)》 - 1.44MB 게임 개발 명세서 (Design Spec)

## 1. 개요 및 대회 제약 조건 (Overview & Constraints)

- **공모전명**: 1.44MB GAME_DEV CONTEST (2P GAME ARCADE)
- **절대 한계 용량**: **1,474,560 바이트 이하** (3.5인치 HD 플로피 디스크 용량, 압축 해제 후 전체 파일 합계 기준)
- **실행 형식**: **독립 실행 파일 (Standalone Executable)** (웹 브라우저 실행 금지)
- **개발 스택**: C/C++ (Raylib 경량 정적 링킹 + 커스텀 서브시스템)
- **개발 환경**: Conda 환경 (`conda activate min`)
- **핵심 테마**: 탄생부터 죽음까지 한 사람의 전 생애를 다루는 내러티브 어드벤처 & 감성 여정

---

## 2. 핵심 연출 및 게임플레이 메카닉 (Core Mechanics & Presentation)

### 2.1 아기 1인칭 시점 및 기억의 깜빡임 (Infant 1st-Person & Sensory Experience)
- **초기 시점**: 갓난아기의 시야 (흐릿한 블러 효과, 눈 깜빡임 Blink 연출).
- **감각적 언어**: 글자 대신 기호(`~♩♪~`, `...`)와 부드러운 칩튠 옹알이 소리.
- **단편적 기억 점프**: 아기의 기억은 연속적이지 않고 순간으로 점프 (모빌 $\to$ 부모님의 손 $\to$ 첫 장난감 $\to$ 첫 걸음마).
- **시점 확장 전환**: 첫 걸음마를 떼며 바닥을 딛는 순간, 카메라가 줌아웃되며 **3인칭 횡스크롤 여정**으로 자연스럽게 전환.

### 2.2 점진적 성장 & 실시간 신체/환경 보간 (Seamless Aging Morphing)
- 챕터 간 불연속 점프가 아닌, 걸음과 진행도(0.0 ~ 100.0)에 따른 실시간 선형/곡선 보간.
- **신체**: 키/체형 스케일, 어깨너비, 등 굽음 각도, 지팡이 유무.
- **팔레트**: 흑발 $\to$ 갈색 $\to$ 희끗한 회색 $\to$ 백발 그라데이션.
- **걸음 속도 & 애니메이션**: 뒤뚱거림 $\to$ 가벼운 발걸음 $\to$ 힘찬 보폭 $\to$ 묵직한 걸음 $\to$ 느리고 신중한 걸음.
- **배경 사계절**: 봄(연두/분홍) $\to$ 여름(짙은 녹음) $\to$ 가을(단풍/갈색) $\to$ 겨울(설경/회백색) 팔레트 실시간 전이.

### 2.3 비선형 시간 가속 시스템 (Psychological Time Acceleration)
- **유년기 ~ 청소년기 (느린 시간)**: 하루가 길고, 사소한 디테일(구름, 꽃, 친구와의 긴 오후)을 깊게 음미.
- **성인기 ~ 중년기 (가속되는 시간)**: 낮과 밤, 계절의 전환 주기가 지수 곡선($t^k$)으로 점점 빨라짐.
- **노년기 (초고속 계절 & 느린 몸)**: 계절은 순식간에 지나가지만 플레이어의 걸음은 느려져 세월의 무상함과 애틋함을 극대화.

### 2.4 죽음과 인생 장면 회상 시스템 (Death & Scenic Memory Reminiscence)
- 플레이어가 전 생애 동안 거쳐온 주요 선택, 만났던 인연, 상호작용한 오브젝트의 '스냅샷/이벤트 플래그'를 메모리에 순차적으로 기록.
- 마지막 5막(임종)에서 주인공이 걸음을 멈추고 빛으로 승화할 때, **플레이어가 실제로 플레이했던 과거의 장면들이 파노라마처럼 시네마틱으로 재현(Scenic Reminiscence)**.
- 마지막에 삶의 요약 앨범과 엔딩 메시지 출력.

## 3. 닌텐도식 극단적 용량 절감 기술 아키텍처 (Nintendo Optimization Techniques)

### 3.1 비주얼: 메타타일(Metatile) & 팔레트 LUT (슈퍼 마리오 / 젤다 방식)
- 텍스처 이미지 파일을 대량 포함하지 않고, 단일 그레이스케일 베이스 타일셋(16x16 / 32x32)을 인덱싱.
- 사계절/밤낮/실내외 분위기는 컬러 룩업 테이블(LUT)과 팔레트 스왑 셰이더로 실시간 처리하여 비주얼 에셋 용량을 **50KB 미만**으로 압축.
- 좌우 대칭 스프라이트 미러링 적용.

### 3.2 사운드: 0바이트 오디오 & 4채널 칩튠 신디사이저 (게임보이 APU 방식)
- WAV, OGG, MP3 등 사전 렌더링된 사운드 파일 일절 배제 (0바이트).
- C/C++ 내부에서 실시간 오디오 버퍼를 채우는 **초경량 4채널 소프트웨어 신디사이저** 내장:
  - 채널 1: Pulse Wave (Lead Melody / 오르골 / 아르페지오)
  - 채널 2: Pulse Wave (Harmony / Counterpoint)
  - 채널 3: Triangle Wave (Bass / Soft Pad)
  - 채널 4: Noise Wave (Percussion / SFX / 빗소리 / 바람소리)
- '인생의 테마' MML 악보 데이터 배열(수백 바이트)을 기반으로 생애 주기별 템포와 음색을 동적 변조.

### 3.3 시나리오 모듈화 (Modular Scenario Script Engine)
- 스토리와 대사, 씬 트리거는 코드와 완전히 분리된 데이터 테이블(C 구조체 배열)로 모듈화.
- 손쉬운 시나리오 수정 및 확장이 가능하며, 초기 프로토타입은 **테스트 시나리오**로 구동 후 추후 본편 시나리오로 즉시 교체 가능.

### 3.4 한글 비트맵 폰트 & 텍스트 바이트 패킹
- 한글 조합형 비트맵 렌더러 또는 필수 완성형 글립 비트맵 폰트 내장 (~30KB).
- 텍스트는 인덱스 압축 및 가변 길이 인코딩.

## 4. 시스템 아키텍처 및 모듈 구성 (System Architecture)

```
┌────────────────────────────────────────────────────────┐
│                      main.c / Core                     │
└───────────────────────────┬────────────────────────────┘
                            │
   ┌────────────────────────┼────────────────────────┐
   │                        │                        │
┌──▼───────────────┐ ┌──────▼──────────────┐ ┌───────▼──────────────┐
│  Renderer &      │ │  Audio Synth        │ │  Life & Scenario     │
│  Palette Engine  │ │  (4-Channel APU)    │ │  State Machine       │
│  - Metatiles     │ │  - Wave Generators  │ │  - 5 Acts Transition │
│  - Palette LUT   │ │  - MML Note Player  │ │  - Time Acceleration │
│  - Character     │ │  - Procedural SFX   │ │  - Memory Shards     │
│    Morphing      │ │  - Dynamic Tempo    │ │  - Scenic Playback   │
└──┬───────────────┘ └─────────────────────┘ └───────┬──────────────┘
   │                                                 │
┌──▼───────────────┐                         ┌───────▼──────────────┐
│ Bitmap Font Text │                         │ Modular Scenario     │
│ & UI System      │                         │ Data Table           │
└──────────────────┘                         └──────────────────────┘
```

### 모듈 상세
1. `core/engine`: 게임 루프, 윈도우 생성, 입력 처리, 델타 타임 제어.
2. `render/palette`: 팔레트 색상 테이블, 픽셀 셰이더/LUT, 타일맵 렌더러, 스프라이트 모핑.
3. `audio/synth`: 4채널 실시간 파형 생성기, MML 파서, 악보 시퀀서, 효과음 트리거.
4. `game/life`: 나이($0.0 \sim 100.0$), 시간 가속 곡선, 1인칭 아기 시점 제어, 3인칭 횡스크롤 카메라.
5. `game/scenario`: 씬 트리거, 대화창, 선택지 분기, 교체 가능한 테스트 시나리오 데이터셋.
6. `game/memory`: 플레이어의 선택 및 방문 장면 스냅샷 기록, 5막(임종) 시네마틱 회상 재생기.

## 5. 최종 바이너리 용량 예산 (Size Budget)

| 구성 요소 | 할당 크기 | 비고 |
| :--- | :--- | :--- |
| 실행 바이너리 (C/Raylib 스트립 빌드) | ~400 KB | 컴파일러 최적화 (`-Os -flto -s`) |
| 내장 한글 비트맵 폰트 | ~35 KB | 8x12/12x12 가변폭 비트맵 |
| 타일셋 및 비주얼 베이스 데이터 | ~45 KB | 그레이스케일 베이스 + 팔레트 데이터 |
| 4채널 MML 악보 & SFX 테이블 | ~10 KB | 5개 생애 테마곡 및 사운드 프리셋 |
| 시나리오 텍스트 & 기억 이벤트 데이터 | ~30 KB | 5개 막 대사 및 선택지 구조체 |
| **총합 (Total Uncompressed)** | **~520 KB** | **1,474,560 바이트의 약 35% (여유 950KB+)** |

## 6. 검증 계획 (Verification Plan)

1. **용량 검증**: 빌드 산출물의 실제 바이트 수를 정확히 측정하여 `1,474,560 bytes` 미만임을 확인하는 자동 체크 스크립트 작성.
2. **단독 실행 검증**: 외부 DLL 의존성 없이 단독 실행(.exe / 맥 실행 파일) 가능한지 검증.
3. **게임플레이 완주 검증**:
   - [ ] 아기 1인칭 시점 (눈 깜빡임, 옹알이, 기억 점프, 첫 걸음마 시점 전환) 동작
   - [ ] 유년기 $\to$ 청소년기 $\to$ 성인기 $\to$ 노년기 점진적 신체 모핑 및 시간 가속 동작
   - [ ] 씬 트리거 및 선택지 데이터 수집 동작
   - [ ] 5막 임종 시 내가 플레이한 여정의 시네마틱 회상 재생 동작
   - [ ] 4채널 신디사이저 BGM 및 SFX 실시간 무오류 사운드 출력
