# 개발자 노트 (Developer Note) - '나의 불편함' TUI 대시보드

이 문서는 업무 시작 전 항상 켜두고 시스템 상태를 모니터링하며, Antigravity 플러그인 및 각종 개발 유틸리티를 손쉽게 제어하기 위한 **개인용 TUI(Terminal User Interface) 대시보드**의 개발 계획 및 설계 명세서입니다.

---

## 1. 프로젝트 개요
* **프로젝트명**: 나의 불편함 (My Inconveniences Dashboard)
* **목표**: 매일 작업 시작 전 실행하여 필요한 개발 설정을 켜고 끄며, 인터넷 상태 및 충전 와트 등의 장비 환경을 한눈에 파악할 수 있는 개인용 터미널 대시보드 구축.
* **주요 철학**: 
  - **신속성**: 지연 시간 없이 즉각 켜지고 작동해야 함 (Go 바이너리 실행).
  - **시각적 명확성**: 깔끔하고 보기 좋은 모던 TUI 레이아웃 적용.
  - **확장성**: 향후 필요한 모니터링 항목이나 도구 연동을 쉽게 추가할 수 있는 아키텍처 구성.

---

## 2. 기술 스택
* **주 언어**: Go (Go 1.20+)
* **TUI 프레임워크**: Charm CLI 에코시스템
  - **[bubbletea](https://github.com/charmbracelet/bubbletea)**: Elm 아키텍처 기반의 TUI 이벤트 루프 및 상태 관리
  - **[lipgloss](https://github.com/charmbracelet/lipgloss)**: 레이아웃 배치, 테두리, 글자 색상, 스타일 정의
  - **[bubbles](https://github.com/charmbracelet/bubbles)**: 스피너, 뷰포트, 리스트 등 내장 컴포넌트 활용
* **빌드/실행 환경**: macOS (Apple Silicon 호환)

---

## 3. 핵심 기능 정의

### ① Antigravity 플러그인/스킬 토글 (Plugin Manager)
* **대상 플러그인**: 
  1. `frontend-design`
  2. `karpathy-guidelines`
  3. `superpowers`
* **동작 방식**:
  - 활성화 상태인 플러그인은 `~/.gemini/config/plugins/<plugin_name>` 경로에 위치함.
  - 비활성화(토글 Off) 시 해당 폴더를 `~/.gemini/config/plugins_disabled/<plugin_name>` 경로로 이동(Move)시켜 즉시 인식을 방지.
  - TUI에서 간편하게 키보드 단축키(예: `1`, `2`, `3` 또는 방향키+Enter)로 상태를 변경할 수 있도록 인터페이스 제공.

### ② 시스템 & 환경 모니터링 (System Monitor)
* **충전 속도 및 배터리 상태**:
  - macOS 명령인 `pmset -g batt` 및 `ioreg -rw0 -r -c AppleSmartBattery` 결과 분석.
  - 현재 배터리 잔량(%) 및 실시간 충전 전력(Wattage) 정보를 파악해 UI에 표시.
* **인터넷 속도 및 연결 상태**:
  - **실시간 지연 시간(Ping)**: 3초 주기로 구글/클라우드플레어 DNS 서버로 핑을 테스트하여 밀리초(ms) 단위 연결 감도를 실시간 업데이트 (네트워크 대역폭 낭비 없음).
  - **다운로드 속도 (Mbps)**: 대용량 패킷을 받아야 하므로, 10분 주기로 자동 백그라운드 측정하거나 사용자가 `R` 키를 입력했을 때 수동으로 즉시 측정하여 대역폭 낭비 방지.
  - UI 렌더링 스레드를 방해하지 않기 위해 고루틴(Goroutine)을 사용하여 백그라운드 비동기 처리.


### ③ 퀵 런처 (Quick Launcher)
* **깃허브 바로가기**: `g` 키 입력 시 사용자의 웹 브라우저에서 지정된 GitHub 리포지토리나 프로필 페이지를 즉시 열어줌 (`open https://github.com/...`).
* **작업 디렉토리 열기**: `o` 키 입력 시 현재 워크스페이스 경로를 Finder로 열어줌 (`open .`).

## 4. UI 레이아웃 설계 (Layout)

```
┌────────────────────────────────────────────────────────────────────────┐
│  나의 불편함 Dashboard v1.0.0                      2026-07-14 01:00:00   │
├──────────────────────────────────────┬─────────────────────────────────┤
│ [🔌 Antigravity 플러그인 제어]       │ [🖥️ 시스템 상태 모니터]          │
│                                      │                                 │
│  [●] 1. frontend-design              │  ● 인터넷 상태: 연결됨 (24ms)   │
│  [○] 2. karpathy-guidelines          │  ● 배터리 상태: 충전 중 (98%)   │
│  [●] 3. superpowers                  │  ● 실시간 전력: 65W (PD 충전)   │
│                                      │                                 │
│  (단축키 1, 2, 3으로 즉시 ON/OFF)    │  [ R ] 속도 측정 다시 실행       │
├──────────────────────────────────────┼─────────────────────────────────┤
│ [📂 퀵 런처 및 유틸리티]             │ [📝 오늘의 기록 / 메모]          │
│                                      │                                 │
│  • [G] 깃허브 리포지토리 열기        │  업무 시작 전 체크리스트:       │
│  • [O] Finder에서 작업 폴더 열기     │  [x] 모니터 켜기                 │
│                                      │  [ ] 텀블러에 물 떠오기         │
└──────────────────────────────────────┴─────────────────────────────────┘
  [q] 종료  |  [Tab] 포커스 전환  |  [Space/Enter] 선택/동작
```

* **테마**: 보라색/블루 톤의 HSL 색상 조합으로 구성하여 모던하고 테크니컬한 감성 극대화.
* **인터랙션**: 키보드 단축키를 활용한 즉각적인 제어 및 화면 크기 조절 시 자동 레이아웃 조정.

---

## 5. 향후 확장 계획
* **불편 로그 기록**: 작업 도중 발생하는 모든 사소한 불편이나 방해 요소를 대시보드 내에서 즉시 메모하여 로컬 `inconveniences.json`에 영구 기록.
* **인터넷 속도 고도화**: 단순 연결 체크를 넘어 실제 Fast.com 또는 Speedtest CLI 인터페이스를 백그라운드 연동.
