# 검증 상태

2026-10-06 현재:

- 웹판 54개 Node 모의 테스트 통과. X 네트워크는 가짜 응답을 사용했습니다.
- Vite 프로덕션 빌드 통과.
- `npm audit --omit=dev`: 실행 의존성에서 보고된 알려진 취약점 0개. 개발 의존성 또는 아직 알려지지 않은 취약점까지 없다는 보증은 아닙니다.
- 보존 ID, 계정 불일치, 승인 목록 변조/만료/재사용 목적 변경, 다른 사이트 요청, JSON 크기 제한, OAuth state·PKCE, 암호화된 사용자별 API 설정, 리포스트 원본 보호 등을 모의 테스트했습니다.
- 브라우저 제어가 연결되지 않았고 macOS 컴퓨터 조작 권한도 없어 웹 화면의 시각·사용성 검증은 아직 하지 못했습니다.
- 실제 X 앱 Client ID/Secret이 없으므로 실제 OAuth·계정 검증·DELETE는 실행하지 않았습니다.
- Vercel CLI 설치 및 계정 확인 완료: **Logged out**. 사용자 소유 프로젝트를 생성하거나 공개 배포하지 않았습니다. Vercel 로그인과 배포 도메인/서버 환경변수 설정이 필요합니다.
- CLI 설정은 `deploy/.vercel-user/`에 두고 Git·배포에서 제외했습니다. 로컬 웹 서버 암호화 키 `.env.local`도 제외합니다.

개인용은 Conda `min` / Python 3.8.13에서 118개 테스트가 통과했습니다. Tk 화면 생성과 두 탭 초기화를 확인했으며, 실제 계정 로그인·삭제와 사람이 수행하는 전체 화면 흐름 검증은 남아 있습니다.
