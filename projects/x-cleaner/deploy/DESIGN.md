# 디자인 방향과 검토

Frontend Design 및 Emil Kowalski의 emil-design-eng 지침을 적용했습니다. 대상은 본인의 X 기록을 정리하려는 사용자, 화면의 목적은 직접 선택한 항목과 실행 범위를 혼동 없이 검토하는 것입니다.

- 색상: 작업 공간 `#F5F7FB`, 표면 `#FFFFFF`, 본문 `#19243B`, 보조 `#65728C`, 선택 `#315EEA`, 최종 실행 `#C84751`.
- 글꼴: 제목/브랜드 Avenir Next 및 한국어 시스템 글꼴, 본문 Apple SD Gothic Neo/system-ui, ID Monaco/monospace. 외부 폰트 요청 없음.
- 배치: 왼쪽 아카이브 목록, 오른쪽 실행 영수증. 모바일에서는 목록 다음에 영수증 표시.
- 기억할 요소: 점선으로 분리된 실행 영수증에서 선택 밖 기록과 삭제/리포스트 취소를 함께 확인.

```text
브랜드                              사용 안내
내 기록을, 내가 고른 만큼.
아카이브 선택 → 항목 고르기 → 확인 후 실행
┌──────────────────────────┬─────────────────┐
│ 종류 필터 / 검색          │ 실행 영수증      │
│ 직접 선택하는 기록 목록   │ 선택 밖 / 대상 수 │
│ 링크·ID 추가 선택         │ 보존 / 확인 단계  │
└──────────────────────────┴─────────────────┘
```

목록 선택은 반복 작업이므로 이동 애니메이션을 넣지 않습니다. 버튼의 포인터 눌림 반응만 140ms CSS transform으로 처리하고, 키보드와 reduced-motion에서는 이동 효과를 제거합니다. HyperFrames는 영상/타임라인 모션이 필요한 화면이 아니므로 사용하지 않았습니다.

| Before | After | Why |
| --- | --- | --- |
| 삭제와 리포스트 취소를 같은 숫자로만 표현 | 종류별 삭제/취소 수와 실행 대상 밖 수 표시 | 실제 요청 범위를 이해할 수 있도록 함 |
| 선택 변경 후 이전 승인 유지 가능 | 선택·보존 문구 변경 시 이전 승인 사용 차단 | 화면의 선택과 실행 목록이 어긋나는 것을 방지 |
| 일반 hover를 터치에도 적용 | 정밀 포인터와 hover 지원 기기에만 적용 | 모바일에서 눌림 상태 고착을 방지 |
