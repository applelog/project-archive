# 구현 및 검증 결과

검증일: 2026-10-06

최종 범위는 **선택한 내 게시물·댓글 삭제와 선택한 내 리포스트 취소**입니다. 선택하지 않은 항목을 일괄 삭제하는 기능은 없습니다.

## 확인한 결과

- 작업 위치: `/Users/YOUR_USERNAME/Desktop/x-cleaner`.
- Python 3.14.7 기반 `.venv` 생성 및 실행·테스트 의존성 설치 완료.
- 모의 테스트 **111개 통과**. 테스트에서 실제 소켓 연결을 차단합니다.
- `pip check`: 깨진 의존성 없음.
- 예제 아카이브 6건에서 게시물·댓글·리포스트 각 1건, 총 3건만 선택됨. 선택 밖 3건은 대상에 없음.
- 기본 `run`은 API 없이 미리보기만 수행함.
- 온라인 검증되지 않은 작업에 `--execute`를 지정하면 인증/API 연결 전에 차단됨.
- 모의 API에서 선택 항목만 처리하고 선택 밖 게시물·댓글·리포스트와 원본 게시물이 남는 것을 확인함.
- 보존 충돌·보존 ID 미발견·계정/작성자 불일치·수정 이력 보호·중단/응답 유실 후 이어하기·재시도 상한과 서버 대기 시각을 검증함.
- PKCE state/S256, 토큰 회전 저장, 인증 파일 권한, 비밀값을 출력하지 않는 오류 처리와 출력 경로의 심볼릭 링크 차단을 검증함.

## 재현 명령

```bash
cd ~/Desktop/x-cleaner
.venv/bin/python -m pytest
.venv/bin/python -m pip check
.venv/bin/python -m x_cleaner run --job jobs/demo-preview
```

pytest 임시 파일도 프로젝트의 `.pytest_tmp/` 아래에 생성하며 Git에서 제외합니다. 미리보기 결과는 `jobs/demo-preview/summary.json`, `targets.json`, `targets.csv`에 있습니다.

## 아직 확인하지 않은 항목

실제 사용자 아카이브와 실제 X 인증 정보는 사용하지 않았습니다. **실제 X 계정의 게시물·댓글 삭제나 리포스트 취소 요청은 보내지 않았습니다.** 실제 계정 연결, 해당 앱의 엔드포인트 접근 권한·요금, 사용자의 실제 아카이브 형식 호환성은 사용자가 자료를 준비한 뒤 별도로 확인해야 합니다.

공식 API 인증·요금·요청 제한·수정 이력의 삭제 의미와 사용 절차는 `README.md`에 출처 링크와 함께 기록했습니다.
